**Minecraft REST API Engine** — это полностью автономный (Zero-Touch) комбайн для развертывания, оптимизации и управления сервером Minecraft без необходимости работать в терминале. Проект превращает обычный домашний ПК в профессиональный игровой хостинг с управлением через современный Web-дашборд и HTTP-запросы.

Специально настроен для комфортной игры через **TLauncher** (пиратский/offline режим), оснащен защитой от зависших процессов и продвинутым менеджером миров.

---

## ✨ Основные возможности

*   🤖 **Zero-Touch Автоматизация:** При первом запуске скрипт **сам** скачивает и устанавливает портативную Java 21 (Adoptium/Temurin), оптимизированное ядро **PaperMC** и обязательные плагины, не требуя никаких действий от пользователя.
*   ⚡ **Анти-Зомби защита (Zombie Killer):** Больше никаких ошибок `java.io.IOException: файл заблокирован`. Перед каждым стартом лаунчер находит и уничтожает зависшие фоновые процессы Java, освобождая память и файлы мира.
*   🌐 **100% Headless & Web-Дашборд:** Консоль больше не нужна. Живые логи, управление питанием, погодой, выдачей прав админа (`op`) и киком игроков происходят в браузере в один клик.
*   🗺️ **Менеджер миров (World Manager):** Горячее переключение между разными картами (Выживание, Skyblock, Креатив) за 1 секунду. Безопасная фоновая генерация **ZIP-бэкапов** без остановки игры.
*   🚀 **Максимальная оптимизация:** Использование ядра PaperMC в связке с **Aikar's Flags** (продвинутыми флагами сборщика мусора G1GC) гарантирует стабильный 20 TPS даже на слабых ПК.
*   🏴 **Готовность к TLauncher (Out-of-the-box):** 
    *   Автоматически устанавливается плагин **ViaVersion** (позволяет заходить игрокам с более старых или новых версий Minecraft).
    *   Автоматически ставится **SkinRestorer** (возвращает скины игрокам на пиратских клиентах).
*   🔌 **Полноценный REST API:** Управляйте сервером со своего смартфона, подключите к нему Discord-бота или создайте собственное приложение.
